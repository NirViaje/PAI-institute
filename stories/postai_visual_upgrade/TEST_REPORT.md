# 本次验证记录

本地构建与浏览器测试使用人工生成的测试音轨，不包含用户本机的真实豆包配音。未重新调用语音 API。

## 已执行

1. 8 项 Python 单元测试通过：完整构建、原文件哈希不变、缺失音频拦截、重复字幕拦截、目录越界拦截、远程音频拦截、目录定位、旧桥接脚本移除与单文件嵌入（部分项目在同一测试中检查）。
2. Headless Chromium 实际播放测试音轨，验证 1× → 2× 的媒体时间增长、即时改速不重播、暂停位置不变、继续播放。
3. 实际 Canvas + Web Audio + MediaRecorder 输出文件，经 FFprobe 确认包含视频及音频流；音量检测确认音轨非静音。
4. 录制暂停/继续；录到选定范围末尾自动结束；分别使用 MP4 容器和 WebM 容器。
5. 本地 HTTP 服务实际请求：配置读取、无效会话令牌被拒绝、上传录制、FFmpeg 压缩、下载结果。
6. 转码结果经 FFprobe 确认为 H.264 / AAC、1280×720、24 fps。
7. 205 条字幕在两种画幅、三个时间位置共 1,230 次绘制检查；字幕分页未报告超出可用高度。
8. 桌面、390px 手机布局截图检查；无页面横向溢出；浏览器脚本未报告错误。多种关键图示人工看图复核。
9. 发布包不包含测试音轨、真实配音、API 凭证、Python 虚拟环境或字体文件。

## 边界

- 测试环境为 Linux / Chromium，不是对所有 Windows 浏览器组合的认证。
- Windows 启动脚本检查了 ASCII 编码与 CRLF 行尾；没有在原生 Windows 上运行。
- 本地文件分离式配音录制应通过 127.0.0.1 工作室页面；普通双击 HTML 只保证正常播放路径，不默许无声录制风险。
- 原声线保留来自“不修改音频文件”的构建方式；实际音色与原豆包生成结果完全相同，并未在本环境重新试听用户整剧。
- 长对白的字幕位置仍是文字权重近似，不是语音识别生成的逐字时间戳。
- 录制实时执行，切到后台会暂停；不会承诺后台快速导出整剧。
- MP4 是容器名称，浏览器原生录制的内部编码可能不同。向外分享宜使用已验证的本地 H.264 / AAC 转码结果。

# AI杠杆下的40亿人工业化｜交互研究系统 v1.0

后AI研究所 · 研究快照：2026年10月23日

**从“第一座工厂能否建成”，走向“当地能否维护、改进并再生产第二座”。**

## 打开

在允许本地HTML运行JavaScript的浏览器中打开 `index.html`。页面中的数据、地图、样式、计算逻辑、品牌图标和二维码全部内置，不需要联网、登录、安装依赖或配置API。没有在线AI调用、实时行情或云端同步。

顶部“导览”适合沿叙事阅读；切换“研究”可看到更多假设和公式。“演示视图”隐藏桌面侧栏。移动端使用顶部可横向滑动的章节导航。

首次打开建议按“总览 → 非洲地图 → 能力阶梯 → 资金 → 能源物料 → 生活 → 未来分岔 → 证据库”阅读；需要直接试算时进入“资金实验室”。

## 已实现

九章交互叙事；四种非洲数值原型、两种非洲定性对照与两种亚洲数值参照；25年资金/外汇双约束模型；AI成本分解与token服务计算器；矿业现金桥；农业粮食/用水/现金桥；168小时合成供电压力测试；独立收益分配实验；能力验收清单；四种条件化未来；22条证据/方法记录；8组研究问题；来源搜索、主题筛选与收藏；本地研究笔记；情景保存对照；年度CSV、研究JSON及Markdown简报导出；JSON备份导入。

页面从不把国家财政、企业利润、居民收入和外汇额度混称为一笔钱；不把模型输出伪装为实测国别数据。

## 保留研究

参数、收藏、能力清单、最多3组保存情景和最多100条笔记，尝试保存在当前浏览器的 `localStorage`。文件移动位置、浏览器隐私设置、清理站点数据或使用不同浏览器，都可能导致原存储不再可见。**请用右上角“导出研究”备份JSON。** 存储不可用时会明确提示，页面仍能运算和导出。

JSON导入会替换当前浏览器内本系统记录，导入前有确认。输入被限制在允许的范围、枚举和长度内；笔记文本按纯文本显示，来源只接受HTTP/HTTPS地址。打开外部来源会联网，但不会自动把笔记发送给来源网站。

## 文件结构

- `index.html`：可独立使用的完整页面。
- `src/model.js`：无DOM依赖的纯计算函数，可由Node直接调用。
- `src/app.js`：交互、叙事、图表、导出与本地存储。
- `src/style.css`：响应式视觉样式。
- `src/shell.html`：页面入口模板。
- `data/research.json`：证据库、区域参数、研究问题与地图几何。
- `data/sources.json`：独立来源登记表。
- `docs/研究方法与叙事设计.md`：研究边界、公式、误读风险与下一阶段实地数据需求。
- `docs/源文件恢复与基准.json`：继承模型的范围与六个回归核对值。
- `tests/test_models.js`：模型基准、会计与能量恒等式、参数压力测试。
- `tests/test_browser.py`：桌面/移动浏览器交互与导出导入检查。
- `tests/model_results.json`、`tests/browser_results.json`：本轮实际测试结果。
- `assets/`：用户提供的后AI品牌图形。
- `build.py`：用标准库重新打包单文件HTML。

## 修改与复现

修改 `src` 或 `data` 后，在包根目录执行：

```bash
python build.py
node tests/test_models.js
```

浏览器测试需要Python Playwright和Chromium；设置环境变量 `CHROMIUM_PATH` 可指定本机Chromium路径：

```bash
python tests/test_browser.py
```

浏览器测试在本次执行环境通过 `set_content` 注入同一份完整HTML进行，因为该环境策略禁止 `file://` 和本地HTTP导航。检查覆盖真实DOM、脚本、控件、桌面/移动布局、文件导出、JSON导入及无存储权限回退；**没有据此宣称已测试所有用户浏览器或跨重启的localStorage持久性。**

开发时也可使用任意静态服务器托管本目录；这不是运行页面的必要条件。

## 必须保留的边界

40.59亿是此前项目范围，不是本次更新的2026年人口统计，更不是“未工业化人口”。北非是定性比较，不并入这一分母。模型以100万人为需求核算单元，不是假设每100万人能自造完整工业体系。

74.23亿美元的十年增量建设与243.71亿美元的25年物理资本篮子，来自两份不同范围的旧模型，不可混作工业化统一价格。原Excel字节本次未能获取，交付的是依据可读表格重建且经过基准核对的公式，并未声称修改原工作簿。

预测、投资可研、国别财政分析、真实工厂安全放行和电力可靠性评估，均需进一步专业资料与现场验证。本系统是研究、教学和前瞻讨论工具，不是已经校准的国别决策模型。

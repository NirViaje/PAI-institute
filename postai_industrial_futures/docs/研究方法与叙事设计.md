# 从第一座工厂到第二座：研究方法与叙事设计

后AI研究所｜AI杠杆下的40亿人工业化｜v1.0｜2026-10-23

## 一、不是“AI让一切便宜”，而是“什么能力得以留下”

本系统的核心问题是：资源收入购买的第一代设备，能否让当地更有能力维护、改进并制造下一代生产体系？

这一问题比“机器人是否便宜”“矿产够不够”“太阳能面积是否足够”更强。三者可以分别改善，但如果设备停机后无人修复、产品无法满足客户标准、进口支付持续失衡，或收益没有进入居民生活，工业化自举仍未成立。

我们将此前讨论整理为三个需要分别验证的扩散过程：消费扩散、生产扩散、收益扩散。消费扩散表现为买得起先进产品；生产扩散表现为能够持续交付、维护和再生产；收益扩散表现为真实购买力、公共服务、可自主支配的时间与参与权。三者可以互相促进，也可能分离。

Moore’s Law for Everything提供技术降本与收益分配相结合的愿景，但不直接给出具体地区的工业成本曲线。本文据此形成问题，而不把愿景当成已经验证的全球经济定律。[S01]

## 二、九章的叙事分工

| 章节 | 观众首先要改变的判断 | 交互如何帮助检验 |
|---|---|---|
| 总览与叙事 | 工业化不是一次设备采购 | 三种扩散、五步叙事、既有区域模型对照 |
| AI改变哪一环 | 知识便宜不等于完整交付便宜 | 成本结构与兑现比例；价格、功耗独立的计算器 |
| 非洲路径地图 | 非洲不是同一起点 | 四种原型、两种定性对照、资源/能力/互供图层 |
| 能力与依赖 | 能力不是年份或资产清单 | 五级验收清单，明确进口、区域共用与本地能力 |
| 资金实验室 | 有钱和有外汇是两道不同约束 | 25年逐年账本、债务、六个预设与情景对照 |
| 能源与物料 | 年度总量不能替代净现金与时序 | 铜价压力、粮食进口基线、水预算、一周供电 |
| 生活与分配 | 高生产率未必带来广泛生活改善 | 同一增加值的不同分配与住房/公共服务预算 |
| 未来分岔 | 技术进步不能唯一决定社会结果 | 本地能力与收益扩散组成四种条件情景 |
| 证据与研究台 | 一个好故事仍需要反证与修订 | 来源、限制、反方、现场任务、笔记与导出 |

“第一座工厂”是现实切口，“第二座工厂”是贯穿主线的验收隐喻。它不要求每个地区真的复制大型整厂，而是要求关键知识、维护、供应商组织和更新能力在本地或区域网络中留下。

## 四、非洲：从四种起点进入，而非套用一条阶梯

### 铜带：用已有工业采购建立共享维护网络

矿山的稳定采购可能为泵、电机、电柜、焊接、计量和物流提供需求。研究重点不是宣布矿产可以支付全部工业化，而是识别矿山收入中真正可分配的现金，以及当地团队能否逐步承担供应、质量和维护。赞比亚2025年铜产量的官方规模锚点不能替代矿业合同净收益调查。[S08]

优先验证的“第一包”是维修中心、计量、备件和共用能源，而不必先建完整机器人厂。退出条件包括无订单、长期不合格、维护资金不足，以及矿区需求挤占居民水电。矿业飞地即使出口上升，也可能没有留下通用地方能力。

### 西非矿农：先问留下多少，再问加工多深

铝土矿、氧化铝、原铝与制品对应不同能源、资本和市场约束。加工货值上升并不自动意味着净外汇或公共收入上升。几内亚2023年采矿业占出口93%、占政府收入22%，是两个分母不同的结构指标，不是利润率或可投资份额。[S07]

深加工应与其他用途竞争同一份可靠电力、外汇和环境容量。农食、包装、建材、港口维修等可作为先形成稳定交付的方向；不是预设所有低利润、高耗能环节都必须留在当地。

### 东非农业服务：从每天的损耗与维修需求开始

已有耕地上的减损、保鲜、分级、食品检验、灌溉维修和共享农机，可以形成无需假定世界级矿山的路径。必须先补本地粮食缺口，再计出口；不能把压低农户收入、不可持续取水或没有买方的余粮称为利润。

太阳能也不是唯一能源：地热、水电、风能、区域电网与可调能力均应按实际条件评估。本系统使用太阳能作可交互例子，不声称适用于全大陆的单一能源配方。[S16、S17]

### 低收入内陆：不能让最需要服务的人被回报率模型排除

起点外汇薄弱、小市场、运维困难、跨境运输与公共安全约束，可能使完整工业园不如水电、粮食保存与移动维修优先。基础服务不应只凭商业回报筛选。赠款、长期低成本融资与区域共享能力需要作为明确的制度选择进入，而不是在模型里假装所有地区都能单独自举。

IEA的电力接入研究讨论资金、风险和可负担性；其“电力接入投资”不是完整工业供电成本，更不是全面工业化总价。[S02、S03]

南部既有工业网络与北非港口制造网络作为定性对照，没有借用其他原型数字伪造国家预测。

## 五、资金模型：透明的双约束，而不是自动成功的增长曲线

单位为每100万居民、百万不变美元。假设固定人口、固定汇率，25年。年度计划在前5年每年占目标2%，第6—15年每年3.5%，第16—25年每年5.5%。允许追赶积压，但当年建设不超过原年度计划的1.25倍。

核心关系如下：

```text
自身可投现金 = 农业可再投资 + 其他可动员资金 + 矿业分配
             + 已有新增经营资产的净现金 − 公共资产维护 − 额外公共支出

当年可用现金 = 期初资金 + 自身可投现金 + 赠款 + 贷款提款 − 实付本息
当年外汇额度 = 期初额度 + 净外汇贡献 + 外部融资 − 实付本息

实际建设 = min(计划积压与施工能力, 目标余量,
               可用现金, 外汇额度 / 建设进口率)
```

外汇额度代表支付进口的限制，已经是现金来源/用途的另一种属性，不能与可用现金加总。原型参数中的经营净现金率假定已扣经营运维、更新准备和外方分红；非经营资产再扣1%维护。

贷款前5年均匀拨付，当年新提款次年计息，第6—25年等额本金。偿债优先，先付息再还本；未付利息资本化，未还本金不能再重复加到债务存量。没有无限再融资。累计“未足额支付发生额”可能包含跨年重复到期本金，不等于期末债务。

如果额外公共支出造成基本资金或外汇负数，显示支出缺口，并把可用于新建设的额度限制为非负。**这不意味着缺口服务已经交付，也不是对不足部分进行了免费融资。**

本次扩展包括临时矿业/干旱/供应商冲击、额外公共服务支出，以及“本地化随年份”与“本地化随累计建设进度”的反事实比较。供应商退出被简化为短期经营贡献和外汇减少，不能作为真实供应商故障模型。

重要限制：经营收益仍按投入美元资本计提。因此，同等物理篮子更便宜时，没有独立估算不变物理产能对应的收入；这会限制降本反事实的经济解释。下一版应把有效产能、产能利用率、销售价格和成本分别建模。原型增长和净现金率没有实地校准；不存在一般均衡、内生价格、人口迁移或实际合同债务结构。

## 六、工程模型的读法

### 1. AI成本传导

基期成本结构为材料/设备55%、知识/设计15%、安装调试20%、其他10%。默认分别下降20%、90%、30%、0%，得到总成本下降30.5%。这是成本份额算术，不是全球工业成本已下降的证据。新增“兑现比例”用于把演示中的名义节约与合格交付的真实节约分开，不自动改变资金模型。

### 2. token服务与电力

默认覆盖40亿人，每人每天10万新生成token，输入/输出比10、缓存命中率80%，预填充60000 token/s/卡，生成15000 token/s/卡，容量使用率50%，平均IT功率1.25kW/卡，PUE1.2。

```text
卡数 = [输出量 / 生成吞吐 + 未缓存输入量 / 预填充吞吐]
       × 计算负担系数 / (86400 × 容量使用率)
设施功率GW = 卡数 × 1.25kW × PUE / 10^6
年电量TWh = 设施功率GW × 8.76
```

复现约92.59万张卡、1.389GW、12.167TWh/年。它不包含训练、视觉/视频、仿真和全部工业负载。采购价指数变为6不改变卡数、功率或芯片面积；相同服务负担增加100倍则在本模型线性增加资源。逻辑、DRAM/HBM、NAND、封装与端侧需求不能互相冒名替代。

### 3. 铜矿现金桥

年产4万吨、假设售价9000美元/吨、运营现金成本5000、维持复垦750；自由现金流当地留存50%，其中再分配50%。总销售3.6亿美元，计划可用3250万美元。只把售价降低20%，计划可用1450万美元，下降约55.4%。矿价是情景输入，不是当前现货价格。

假设矿山已投产、初建债务已扣除/偿清。绿色新矿的初建资本、基础设施和矿权取得不在这条桥内。不同居民模块不能重复分配同一矿山产量；也不能以矿石质量当精炼金属质量。

### 4. 农业物料与现金桥

100万人、10万公顷已有耕地、基期2吨/公顷、15%损失；同类粮食需求25万吨。默认改造后3.5吨/公顷、15%损失，得到29.75万吨可用粮食：先替代基期8万吨进口，再看4.75万吨可出口盈余。仅当质量、物流和市场条件成立时计出口。

增量销售扣新增农资和合理劳动报酬、采后处理、其他运维、更新与生态准备后再分配；净外汇改善另算，但不作为额外现金重复相加。基准计划现金777.5万美元/年，净外汇改善2787.5万美元/年。用水预算不足则标记约束失败；单产并未依据灌溉量自动响应，不可用该交互证明农艺产量。

### 5. 年度光伏与168小时合成调度

新增交付2TWh/年、光伏全额年度匹配、22% DC容量因子、20%下游损耗/储能/弃光预留，对应约1.297GWp。默认储能为平均负荷的5.256小时，即1.2GWh；这不等于电池额定功率下时长。周演示采用平均负荷1.5倍的充放电功率、90%可用容量、90%往返效率、初始50%荷电，分别显示初末储能。

调度使用合成负荷和正弦太阳能曲线，普通周与三天低光照周可切换。未满足电量只表示这168小时、这个合成策略下的缺口，不是年度失电率、实际天气或国别电网预测。没有全年8760小时、长期季节性、检修或最优调度。

光伏单独LCOE不是工业终端电价。储能初装、电网、可调电源、可靠性和更换费用必须分列。[S04]

## 七、生活分配：会计实验，不是家庭调查

新增增加值先分为劳动和资本收入，按同一简化税率扣税，税后资本收益再按公共权益份额分配。税后劳动、私人资本、税收、公共分红相加严格等于增加值；不能在税后利润之外再免费创造公共资产收益。

每100万人下，百万美元/年的数值等于美元/人·年，但平均到全体居民的劳动收入不是就业者工资或实际家庭可支配收入。住房负担只作增量代理，未估计全部家庭支出、迁移、房价与贫富差异。公共预算不足时显示缺口，不自动发债或发放基本收入。

该实验独立于资金模型，不把同一经营利润、税收或进口节约重复划拨。其目的是使同一生产率增长的分配分岔可见，而非推荐统一税率或资产所有制。价值上的关注是：基本生活、能力发展、社会参与与生活选择不能只用工厂岗位数量代替。[S01、S06、S12、S13]

## 八、研究系统怎样继续生长

八组研究问题将“工作假说—反方—验证任务—需要数据”同时保存。下一阶段最有用的不是继续增加宏大总量，而是为具体走廊和需求单元建立数据室：矿山采购与净分配、行业用电曲线、维修工单、产线合格率、当地供应商成本、农户净收入、水文许可、真实回款、融资合同与居民生活调查。

选择一处区域后，先建立基线，再分阶段上线AI与组织改造；比较停机、返工、一次修复率、净外汇、维护准备和居民服务可靠性。允许验证结果推翻“AI必然推动本地工业化”的假说。对比组也应包括“可靠进口+强维修”，而非只比较“全本地化”和“什么都不做”。

研究笔记不是经过核验的新事实。导入的参数只能改变本地条件实验，不能自动成为有来源的统计数据。全部原文链接与对应的不能推出的结论见下一节。

## 十、来源登记与使用边界

### S01｜Moore’s Law for Everything

Sam Altman，2021-03-16。类型：观点原文。

支持：AI可能推动广泛降本，但资本收益与制度分配是论证的一部分，而非技术进步的自动附属品。

限制：愿景与规范性主张，不是非洲工业化成本预测。

原始来源：https://moores.samaltman.com/

### S02｜Financing Electricity Access in Africa

IEA，2025-10-20；缺电人口口径2024。类型：机构情景。

支持：约6亿人仍无电可用；ACCESS情景提出到2035年普及电力接入约需1500亿美元。

限制：电力接入不等于工业级可靠供电，更不等于整个工业化投资。

原始来源：https://www.iea.org/reports/financing-electricity-access-in-africa

### S03｜Beyond new connections

IEA，2025。类型：机构分析。

支持：负担能力、服务质量和资本成本会使“接上电”与“用得起电”分离。接入项目资本成本可达发达经济体电网项目的3—4倍。

限制：特定类别项目的比较，不应直接当成所有非洲工业贷款利率。

原始来源：https://www.iea.org/reports/financing-electricity-access-in-africa/beyond-new-connections

### S04｜Renewable Power Generation Costs in 2025
